# Submission checklist

Before uploading the project, I would check the following:

- Start MySQL and import the SQL file.
- Start the FastAPI backend.
- Start the React frontend.
- Test login with all three demo users.
- Check the dashboard values.
- Add one purchase and confirm that it appears in the history.
- Try a transfer between two bases.
- Add an assignment and an expenditure.
- Check the audit log.
- Test that the different roles cannot access everything.
- Take screenshots of the main pages if they are required with the submission.
- Zip the complete project folder, including the database folder.

The application is only a demo project for the assignment. It is not connected to any real military system or real operational data.
